# Dépendances d’Easy Meals

## sqflite

Fournit la base de données SQLite utilisée pour conserver les repas et les menus hebdomadaires.

## path

Permet de construire correctement le chemin du fichier de base de données sur Android.

## flutter_localizations

Fournit les composants officiels de Flutter nécessaires à la traduction de l’interface.

## intl

Permet notamment de formater les dates selon la langue sélectionnée.
